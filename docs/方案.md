# 眼底球面映射系统 (Fundus Sphere Map)

## 项目概述

将 Optos Daytona 200° SLO 视网膜图像映射到 3D 球面，并实现黄斑和视盘的自动检测。

### 目标
- 将 2D 视网膜图像映射到 3D 球体表面
- 自动识别黄斑和视盘位置
- 支持手机拍摄屏幕的图片输入

---

## 技术方案

### 1. 图像输入

#### 1.1 输入来源
| 来源 | 处理方式 |
|------|----------|
| Optos 直出图像 | 直接使用，无需校正 |
| 手机拍摄屏幕 | 预处理（摩尔纹去除 + 透视校正）|

#### 1.2 手机拍摄预处理流程
```
手机照片
  ↓
摩尔纹去除（频率域滤波）
  ↓
透视校正（霍夫圆检测 → 裁剪）
  ↓
亮度归一化
  ↓
YOLO检测
```

---

### 2. 3D 映射算法

#### 2.1 标准眼模型
- 眼轴长度：24mm（标准眼）
- 视网膜半径：≈12mm
- 视场角：200°

#### 2.2 映射公式
```
θ = 角度（从图像中心）
r = R × sin(θ)
其中 R ≈ 12mm（24mm眼轴的视网膜半径）
```

#### 2.3 坐标系转换
- 图像坐标 (x, y) → 极坐标 (r, θ) → 球面坐标 (θ, φ)
- 球面坐标到笛卡尔坐标：
  - X = R × sin(θ) × cos(φ)
  - Y = R × sin(θ) × sin(φ)
  - Z = R × cos(θ)

#### 2.4 是否需要眼轴校正？
| 场景 | 是否校正 |
|------|----------|
| 演示程序/简单映射 | ❌ 不需要，直接用24mm模型 |
| 患者个体精确测量 | ✅ 需要按实际眼轴校正 |
| 人群数据标准化比较 | ❌ 不需要，24mm标准化 |

---

### 3. YOLO 目标检测

#### 3.1 模型选择
| 模型 | 大小 | 推理速度(WebGPU) | 推荐场景 |
|------|------|------------------|----------|
| YOLOv8n | ~6MB | ~20-50ms/帧 | ✅ 推荐，轻量且准确 |
| YOLOv5s | ~14MB | ~50-100ms/帧 | 更高精度 |

#### 3.2 浏览器运行方案
```python
# 训练后导出为TF.js格式
yolo export model=best.pt format=tfjs
```

#### 3.3 技术栈
- **模型格式**: TensorFlow.js 或 ONNX Runtime Web
- **加速**: WebGPU / WebGL
- **后处理**: NMS (Non-Maximum Suppression)

#### 3.4 检测目标
- 黄斑 (Macula)
- 视盘 (Optic Disc)

---

### 4. 视盘大小参考

⚠️ **注意**：视盘大小变异较大，不能作为可靠参考标尺

| 参数 | 范围 | 平均值 |
|------|------|--------|
| 水平直径 | 0.91-2.76mm | 1.79mm |
| 垂直直径 | 1.08-2.76mm | 1.97mm |
| 面积 | 0.86-5.39mm² | 2.89mm² |
